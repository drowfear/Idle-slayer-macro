## 🌟 Key Features

* **Active Window Focus Locking**: Automatically detects and locks onto the game window to prevent accidental input sending in other applications.
* **Automatic Administrator Elevation**: Requests UAC Administrator rights upon startup, ensuring keypress injection works correctly in DirectX/OpenGL environments.
* **Instant Pause on Focus Loss**: Automatically suspends key presses whenever you Alt-Tab away from the game.
* **Simple Hotkey Controls**: Quick key combinations to toggle execution or exit cleanly.

## 🚀 Setup & Installation

### Prerequisites

* **OS**: Windows 10/11
* **Environment**: Python 3.8 or higher installed on your system.

### Quick Start

1. Clone or download this repository:
   ```bash
   git clone [https://github.com/drowfear/idle-slayer-macro.git](https://github.com/drowfear/idle-slayer-macro.git)
   cd idle-slayer-macro


2. Install required python packages:

pip install -r requirements.txt

🎮 How to Use

3.Launch Idle Slayer.

4. Run the macro:

python main.py
Click inside your Idle Slayer game window to ensure it is focused.

Press Ctrl + Shift + D while inside the game window to bind it and toggle the macro ON / OFF.

Press ESC at any time to immediately close the script.
